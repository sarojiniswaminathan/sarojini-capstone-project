# Tailoring Business Agent — MVP

Implements the MVP scope from `plan.md` Section 22: Orders + fractional Inventory
+ Projects + college-schedule-aware Scheduling, wrapped in a conversational agent
that answers the four core queries:

1. What should I work on today?
2. Which order should I prioritise?
3. Do I have enough fabric for this order?
4. What needs to be purchased for order X?

## Design

Matches Section 11's split:

- **Deterministic core** (`agent/inventory.py`, `orders.py`, `scheduling.py`, `priority.py`,
  `planning.py`) — all inventory math, dates, reservations, and priority scoring. No AI
  involved, no API key needed. Fully testable on its own.
- **AI layer** (`agent/tools.py`, `agent.py`, `cli.py`) — Claude decides which of the
  deterministic functions to call (as tools), reasons across the results, and explains
  recommendations in plain language. It never touches the database directly.

The **calendar/college schedule is manual input** for this MVP (`add_commitment`) —
Apple Calendar integration is explicitly deferred to a later phase (Section 14).

## Setup

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY=sk-ant-...   # required only for the chat agent
```

## Usage

**Test the deterministic core with no API key** (proves the logic is correct on its own):

```bash
python -m agent.demo
```

Runs all four core queries against seeded example data (mirrors the Order #024 /
#031 / #042 scenarios used throughout `plan.md`) and prints the results.

**Chat with the agent** (requires `ANTHROPIC_API_KEY`):

```bash
python -m agent.cli --seed     # first run: reset + load example data
python -m agent.cli            # subsequent runs: reuse the existing database
python -m agent.cli --fresh    # start from a completely empty database
```

Example things to ask:
- "What should I work on today?"
- "Which order should I prioritise?"
- "Do I have enough fabric for ORD-024?"
- "What do I need to buy?"
- "I have a new dress order due on the 25th, add it" (agent will ask for missing details)
- "I only got one hour of sewing done today on ORD-024" (log a work session)
- "I found another 0.5m of black cotton" (manual inventory correction)

## Data model

SQLite (`agent/tailoring.db`, gitignored, regenerated by `--seed`/`--fresh`). Schema
in `agent/schema.sql`: `materials`, `material_transactions` (audit trail), `orders`,
`projects`, `project_materials` (planned vs. actual, reserved vs. consumed),
`commitments` (manual calendar input), `work_sessions`.

Reserved/available material quantities are always *derived* from active
`project_materials` reservations rather than stored directly, so they can't drift.

## What's deliberately not built yet (per Section 22 / post-MVP phases)

Shopping-trip batching/route optimisation, historical project analysis, Apple
Calendar integration, Instagram/marketing automation, customer inspiration PDF
catalogues. See `plan.md` Sections 22–24 for the full phased roadmap.
